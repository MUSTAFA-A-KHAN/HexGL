# HexGL - GitHub Pages Deployment

This is the GitHub Pages deployment of [HexGL](http://hexgl.bkcore.com), a futuristic racing game built with HTML5, JavaScript and WebGL.

## Playing the Game

Simply open `index.html` in your web browser, or visit:
**https://MUSTAFA-A-KHAN.github.io/HexGL/**

## Controls

- **Arrow Keys / WASD**: Steer and accelerate
- **Space**: Boost
- **Escape**: Pause/Resume

## Features

- WebGL-based 3D graphics
- Multiple control types (Keyboard, Touch, Gamepad, Device Orientation)
- Telegram Mini App integration with Gyroscope controls
- Multiple tracks and ships
- HUD display with speed and shield indicators

## Source Code

The main source code is available in the master branch of the repository:
